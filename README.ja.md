# DisplayKeeper

ディスプレイの詳しい設定を確かめ、変更し、ファイルに保存して、あとからファイルをダブルクリックするだけで元に戻せる macOS アプリです。

ドックやケーブルの差し替え、スリープからの復帰、macOS の更新などで、解像度・リフレッシュレート・回転・配置・ミラーリングが変わってしまうことがあります。
一度保存しておけば、DisplayKeeper が元に戻します。

---

## ダウンロード

[Releases](https://github.com/EVAtiter/DisplayKeeper-release/releases/latest) から最新版をダウンロードしてください。

1. `DisplayKeeper-x.x.x.zip` を解凍し、`DisplayKeeper.app` を「アプリケーション」フォルダへ移動
2. DisplayKeeper を開く。特別な許可は要りません

Homebrew でもインストールできます。

```bash
brew install --cask EVAtiter/tap/displaykeeper
```

Homebrew 7 以降で「untrusted tap」と表示されたら、先に次のコマンドで displaykeeper を信頼してから、もう一度インストールしてください。

```bash
brew trust --cask evatiter/tap/displaykeeper
```

## 使い方

### 保存する

- **ファイル → すべてのディスプレイを保存…**（⌘S）で、接続しているすべてのディスプレイの設定を 1 つのファイル（`.dkset`）に保存します
- **ファイル → このディスプレイを保存…**（⇧⌘S）で、1 台ぶんを保存します（`.dkdisplay`）。そのディスプレイのタブで使います
- **ファイル → ディスプレイごとにフォルダーへ保存…**（⌥⌘S）で、すべてのディスプレイを 1 台ずつのファイルにして、選んだフォルダーへ保存します
- 保存の画面で、含める項目を選べます。含めなかった項目は、ファイルを反映するときに変更されません

### 元に戻す

- DisplayKeeper が起動していないときに、**保存したファイルをダブルクリック**します。ウインドウを出さずに設定を反映し、そのまま終了します。
  反映できなかった項目があるときだけ、お知らせを表示します
- **⌥（Option）キー**を押しながらダブルクリックすると、反映せずにウインドウで開きます
- 保存したファイルを **システム設定 → 一般 → ログイン項目** に入れておくと、ログインのたびに設定を元に戻せます

### 反映する前に確かめる

**ファイル → 開く…**、ウインドウへのドラッグ、または DisplayKeeper の起動中のダブルクリックでファイルを開くと、
ファイルの各ディスプレイが接続中のどのディスプレイに当たるかと、何が変わるかを表示します。**変更として読み込む** を押してから、
ウインドウの **反映** を押してください。1 台ぶんのファイルは、別のディスプレイ（同じ機種のモニターなど）へ読み込むこともできます。

### 設定を変える

ディスプレイごとにタブがあります。値を変えてから、ウインドウの下の **反映** を押してください。押すまでは何も変わりません。
解像度・リフレッシュレート・回転・ミラーリングを変えて反映すると、この設定を維持するかを尋ねます。
15 秒以内に答えなければ元の設定に戻るので、画面が映らなくなっても安心です。

配置は **全体** タブの図で、ディスプレイをドラッグして変えられます。近くの辺に吸い付き、ほかのディスプレイと重なる位置では元に戻ります。

### ショートカット App から使う

**DisplayKeeper のファイルを反映** と **今のディスプレイの設定を保存** の 2 つのアクションがあります。どちらもウインドウを出さずに動きます。
保存のアクションは `.dkset` ファイルを返すので、**ファイルを保存** アクションで保存先を選んでください。

### コマンドラインから使う

Homebrew でインストールすると、`displaykeeper` コマンドが使えます。

```bash
displaykeeper apply ~/Displays.dkset   # ファイルを反映する
displaykeeper save ~/Displays.dkset    # すべてのディスプレイを保存する
displaykeeper dump                     # 今の状態を表示する
```

終了コードは 0 が成功、1 が反映できなかった項目あり、2 がエラーです。
Homebrew を使わない場合は `/Applications/DisplayKeeper.app/Contents/Resources/displaykeeper` を実行してください。

## 主な機能

- **ディスプレイの情報** — メーカーと機種、製造年週、接続、物理サイズと画素密度、現在のモードと選べるすべてのモード、
  カラープロファイル、輝度、DDC/CI の値
- **変更・保存・復元できる設定** — 解像度とリフレッシュレート、回転、配置、メインディスプレイ、ミラーリング、カラープロファイル、
  リファレンスモード（内蔵 XDR ディスプレイなど）、HDR、内蔵ディスプレイの輝度、外部モニターの輝度とコントラスト（DDC/CI）
- **照合** — 保存したディスプレイを、UUID・シリアル番号・機種・接続の場所で見つけ直します。つなぎ直したあとでも当てはまります
- **日本語・英語**

## 注意

- DDC/CI（外部モニターの輝度とコントラスト）は、対応しているモニターでだけ使えます。USB-C の HDMI 変換アダプターやハブ、切り替え機を通すと使えないことがあります。
  使えないときは、ディスプレイのタブにその理由を表示します
- HDR Video や Internet & Web（sRGB）などのリファレンスモードでは内蔵ディスプレイの輝度が固定されるため、選んでいる間は輝度を変更しません
- 別のディスプレイをミラーリングしているディスプレイの解像度と回転は、ミラーリングの元に従うため、個別には変更しません
- ダブルクリックで反映するときは、この Mac で今選べる値だけを反映します。ファイルにあるディスプレイがまだつながっていないときは、最大 10 秒待ちます
- HDR の切り替えは、HDR 対応のモニターでの確認がまだです

## プライバシー

DisplayKeeper はネットワークを使いません。操作の記録や個人情報の保存もしません。
macOS がアプリに提供していないディスプレイの設定を読み書きするため、macOS の非公開のフレームワーク
（SkyLight・MonitorPanel・DisplayServices・CoreDisplay・IOAVService）を使っています。そのため Mac App Store では配布していません。
